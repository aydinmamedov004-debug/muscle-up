Muscle-up is a modern, minimalistic workout tracker built with Flutter.

## Features

- 💪 Custom workout programs
- 📈 Progressive overload tracking
- 🏆 Personal records
- 📊 Progress analytics
- ⏱ Rest timer
- 📅 Workout history
- 🌙 Dark theme
- 📱 Offline support

## Tech Stack

- Flutter
- Dart
- SQLite
- Riverpod
- FL Chart

Currently under active development.
